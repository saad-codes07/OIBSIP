# Level 2 Task 1: House Price Prediction with Linear Regression

## Overview
This project builds an end-to-end regression modeling pipeline predicting housing prices based on structural features and location parameters.

## Checklist Deliverables
* **EDA & Cleaning:** Null imputation, descriptive statistics, target distribution visualization.
* **Feature Engineering:** One-Hot Encoding for categorical neighborhood features.
* **Feature Selection & Heatmap:** Evaluated correlations with house prices.
* **Model Training & Metrics:** Evaluated Linear Regression using MSE, RMSE, and $R^2$.
* **Diagnostic Plots:** Scatter plot of actual vs. predicted prices and residual error analysis.
* **Coefficient Analysis:** Identified features driving price appreciation/depreciation.
* **Bonus Benchmark:** Benchmark comparison against Ridge and Lasso regularized models.
