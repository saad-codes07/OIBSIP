# Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on retail superstore sales data to identify profit drivers, sales trends, regional performance, and the business impact of promotional discounting.

## 🛠️ Tools & Libraries Used
- **Environment:** Visual Studio Code (Jupyter Notebook extension)
- **Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📊 Key Insights
- **Discount Threshold:** Discounts above 20% severely erode net profit, with 50% discounts causing average losses exceeding -$300 per order.
- **Top & Bottom Categories:** Technology is the most profitable product line, while Furniture yields low profit margins despite high sales volume.
- **Geographic Trends:** The West and East regions generate over 60% of total company profits.

## 🚀 How to Run
1. Ensure `pandas`, `matplotlib`, and `seaborn` are installed.
2. Open `eda_retail_sales.ipynb` in VS Code.
3. Run all notebook cells sequentially.
