# Level 1 Task 4: Sentiment Analysis Pipeline

## Overview
This project delivers a full Natural Language Processing (NLP) and Machine Learning pipeline that classifies customer feedback into **positive**, **negative**, and **neutral** sentiment classes.

## Features Implemented
* **Text Preprocessing:** Tokenization, lowercasing, punctuation stripping, and stopword removal.
* **Feature Extraction:** TF-IDF (Term Frequency - Inverse Document Frequency) Vectorization.
* **Model Training:** Trained and benchmarked **Multinomial Naive Bayes** and **Logistic Regression** (80/20 train/test split).
* **Evaluation:** Classification reports, confusion matrices, class distribution plots, and WordCloud visualizations per sentiment.
* **Error Analysis & Insights:** Evaluated model decision boundaries and outlined real-world deployment scenarios.
