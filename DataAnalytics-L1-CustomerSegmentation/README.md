# Task 2: Customer Segmentation using RFM & K-Means Clustering

## 📌 Project Overview
This project performs customer segmentation on transactional data from an online retail store using **RFM (Recency, Frequency, Monetary)** analysis and **K-Means Machine Learning Clustering**. By segmenting customers into distinct behavioral profiles, businesses can tailor marketing strategies, improve customer retention, and maximize customer lifetime value (CLV).

---

## 📊 Dataset Information
* **Dataset**: UCI Online Retail Dataset
* **Initial Records**: 541,910 rows
* **Cleaned Dataset**: 397,884 transaction rows across 4,338 unique customers
* **Key Attributes**: `InvoiceNo`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `UnitPrice`, `CustomerID`, `Country`

---

## 🛠️ Methodology & Workflow

1. **Data Cleaning & Preprocessing**:
   * Handled missing `CustomerID` values.
   * Filtered out cancelled transactions (`InvoiceNo` starting with 'C').
   * Removed negative/zero `Quantity` and `UnitPrice` values.
   * Dropped redundant metadata columns.

2. **RFM Feature Engineering**:
   * **Recency (R)**: Days elapsed since the customer's last purchase relative to the snapshot date.
   * **Frequency (F)**: Total number of unique orders placed by the customer.
   * **Monetary (M)**: Total monetary spend generated by the customer.

3. **Data Transformation & Scaling**:
   * Applied Log Transformation (`np.log1p`) to fix heavy right-skewness across RFM metrics.
   * Standardized features using `StandardScaler` for distance-based clustering algorithms.

4. **K-Means Clustering & Model Validation**:
   * Utilized the **Elbow Method** (Inertia vs. $K$) to evaluate optimal cluster counts.
   * Selected **$K = 4$** as the optimal number of distinct customer segments.

5. **Segment Profiling & Visualization**:
   * Mapped clusters to business personas.
   * Plotted segment count distributions and Recency vs. Monetary spend scatter plots.
