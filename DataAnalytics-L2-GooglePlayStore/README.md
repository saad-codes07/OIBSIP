# Level 2 Task 4: Google Play Store Ecosystem Analysis

## Overview
This project executes a comprehensive end-to-end data analysis of the Google Play Store Android app ecosystem, covering data cleaning, category saturation, revenue estimation, and sentiment analysis on user reviews.

## Checklist Deliverables
* **Data Cleaning Pipeline:** Stripped string noise (`"10,000+"`, `"$4.99"`), converted file sizes (`M`/`k`), imputed null ratings, and removed duplicates.
* **Market Saturation Analysis:** Evaluated category counts identifying high vs. low competition sectors.
* **Pricing & Revenue Estimation:** Calculated total potential revenue across free vs. paid app tiers.
* **Sentiment Analysis:** Categorized user reviews into Positive, Negative, and Neutral sentiment buckets across categories.
* **Interactive Visualization:** Implemented interactive `plotly` scatter plot mapping installs, size, and category distribution.
* **Developer Strategy:** Formulated 3 strategic insights for prospective app launches.
